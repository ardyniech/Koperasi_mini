# Koperasi Mini Syariah - Recruitment & Deployment Guide

## 🚀 Quick Start

### Backend (FastAPI)
```bash
cd ~/koperasi_mini/backend
pip install -r requirements.txt
# Jika port 8006 in use, pakai 8007:
uvicorn app.main:app --host 0.0.0.0 --port 8007 --reload
```

### Frontend (React + Vite)
```bash
cd ~/koperasi_mini/frontend
npm install
npm run dev  # Development (not working on Termux ARM64)
```

---

## ⚠️ TERMUX ARM64 LIMITATION

### Problem
Vite development server dan `npm run build` **CRASH** di Termux ARM64 dengan error:
```
Illegal instruction (exit code 132)
```

**Penyebab**: Native modules (esbuild) yang digunakan Vite tidak kompatibel dengan arsitektur ARM64 di Termux.

### ✅ SOLUSI: Express Static Server

Gunakan Express untuk serve frontend di Termux:

1. **Install Express**:
   ```bash
   cd ~/koperasi_mini/frontend
   npm install express
   ```

2. **Start Express server**:
   ```bash
   node server.js
   ```
   Server akan jalan di `http://localhost:5173`

3. **Cara lain** (jika build hasil ada):
   - Build frontend di laptop/PC: `npm run build`
   - Copy folder `dist/` ke Termux
   - Express akan serve files dari folder `dist/`

## 🔧 ADMIN ACCOUNT SETUP

Akun admin **TIDAK** bisa di-register via halaman register. Admin dibuat oleh pengembang (kita) via:

### Method 1: Manual Database Entry
```bash
cd ~/koperasi_mini/backend
python3
>>> from app.db.session import SessionLocal
>>> from app.models.anggota import Anggota
>>> from app.core.security import get_password_hash
>>> db = SessionLocal()
>>> admin = Anggota(
...     nama="Admin Koperasi",
...     email="admin@koperasi.com",
...     hashed_password=get_password_hash("password_anda"),
...     role="admin",
...     status="aktif"
... )
>>> db.add(admin)
>>> db.commit()
>>> exit()
```

### Method 2: Promote Existing User
Login sebagai user biasa, lalu update role di database:
```sql
UPDATE anggota SET role='admin' WHERE email='user@email.com';
```
